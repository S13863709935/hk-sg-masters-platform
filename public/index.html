Week 4 checkpoint: scope, data design, official-directory entry checks and a first programme pilot.

This branch contains a limited development foundation. It is not the complete platform and does not check admission eligibility.

What is in this checkpoint

  • 14 target universities and directory-source notes.
  • 20 direct-entry programme records for method validation, plus one transfer-only reference.
  • Data fields, evidence states, user-research protocol and test scenarios.
  • A local HTTP service, health check and checkpoint metadata.

Programme-page extraction is not independent human review. Unknown requirements remain unresolved.

Planned platform workflow

Explore programmes → enter background → inspect requirement checks → compare and save options.

These core features are not implemented in this published checkpoint. No student information is collected here.
