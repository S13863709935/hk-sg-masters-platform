- 未知条件、来源冲突和未确认的费用年份保持明确。不会因赶进度创造 GPA 换算、录取概率、“保底”承诺或独立复核。
- 交付包从最新源文件首次建立自己的本地数据库，不附带原日常数据库、真实学生档案、密钥、浏览器存储或 Git 历史。原日常数据库保持原样。
- 本轮检查使用合成背景和内存数据库。真实同学反馈、真实设备覆盖及外部托管仍是后续事项。

## 使用本地交付包

1. 将 ZIP **完整解压**到普通可写文件夹，不要直接在压缩包中运行。
2. 双击解压目录的 `start-local.cmd`。本机启动脚本可使用已安装的 Codex Node；其他电脑需要 Node.js 24 或以上，无需安装额外运行依赖。
3. 打开启动窗口显示的 `http://127.0.0.1:3102`，保持窗口运行。若已有旧版服务，先在旧服务窗口按 Ctrl+C 停止，再启动交付包。
4. 结束时在服务窗口按 Ctrl+C。候选清单及背景的本机记忆由用户主动选择，公开导出不含学生背景。

`LOCAL-DELIVERY.json` 标明打包时间、源提交、文件指纹和是否有未提交修改。初始交付包可用于检查本地流程；只有实际合入并验收的资料才能算进最终数据进度。
