# 本地演示与验收

本说明对应11月10日集中验收后的完整本地版。GitHub第八周阶段版保持单独范围，演示包不代表公开部署或课程提交。

## 启动

将新ZIP完整解压到新的可写文件夹。其他电脑需要Node.js24或以上；本机也可使用已安装的Codex运行环境，无需安装额外项目依赖。双击start-local.cmd，打开窗口显示的本地地址，并保持窗口运行。

若同一端口已有GradPath，启动入口会明确提示，不会声称新版已经启动。到旧启动窗口按Ctrl+C停止旧服务，再启动本份文件；原有数据库及旧服务不由新启动器自动删除或关闭。新文件夹首次正常启动会建立自己的本地数据库。

## 五分钟演示

1. 在Explore programmes搜索Information Systems。说明Subject tag只是整理分类，不是本科专业准入条件。
2. 打开My background，明确说明这是演示用模拟背景。例如Computer Science、GPA3.4/4、IELTS7（四项均7）、考试日期2026-05-01；毕业状态按模拟情景选择。背景记忆默认不勾选。
3. 提交后检查每条已满足、缺口及待确认条件。Recorded comparisons仅覆盖已记录的背景比较；没有录取概率或完整资格保证。
4. 收藏NTU的MSc Information Systems，在详情明确选择August2027／Part-time，再点Remember these choices。旧年度费用只作历史参考，当前未确认费用继续显示未知。
5. 与另一所学校的项目比较，注意各自学制、原币学费、申请类别及来源日期。比较表可在自己的区域横向滚动。
6. 刷新页面，检查被明确记住的兼读选项恢复；未勾选记忆的背景应清空。打开My shortlist并Export shortlist，导出保留选项及公开条件，不含个人背景或匹配结果。

Refresh date comparison仅根据已记录的日期重新计算，不会重新查官网。临近截止和当前可申请是不同概念；以适用类别及最新官方说明为准。

## 演示后

清空模拟背景和候选清单，或在详情Forget remembered choices，避免共享电脑保留演示选择。结束时在启动窗口按Ctrl+C。保留原ZIP和LOCAL-DELIVERY.json，后续只根据可复现问题和官方资料更新维护。

软件检查及桌面浏览器窄屏模拟不等于真实用户研究、真手机或第二台电脑验收。实际同学反馈与额外设备结果应另行如实记录。
