# 项目范围与功能需求

整理日期：2026-10-05。依据此前确认的方向及现有项目计划整理为开发基线。具体实施细节仍需组员复核。

## 目标用户与问题

面向在新加坡考虑继续读硕士的本科高年级学生及近期毕业生。项目起因是 Song Shaoheng 与身边同学的升学需求讨论，香港加入后可提供更多地区选择。这里记录的是项目动机，尚不代表完成了学生调查或证明了市场需求。

课程信息散布于学校中央目录、招生指南和院系项目页。网站整合信息，并解释学生背景与公开要求的关系。

## 覆盖范围

| 地区 | 目标学校 |
| --- | --- |
| 香港 | CityU、HKBU、Lingnan、CUHK、EdUHK、PolyU、HKUST、HKU |
| 新加坡 | NUS、NTU、SMU、SUTD、SIT、SUSS |

只纳入这些学校的 taught／coursework master's，包括符合学校边界的自资授课型硕士。排除研究型学位、博士、独立证书及文凭、边界外私立机构和仅在境外交付的课程。联合项目须核对实际授予学校与授课地点。

学校范围已确定。全量课程规模、当期是否招生和逐项目要求尚待核验。

## 功能需求

| 编号 | 功能 | 基本验收条件 |
| --- | --- | --- |
| F01 | 搜索与筛选 | 可按学校、地区及专业领域查找课程；没有结果时明确提示 |
| F02 | 项目详情 | 显示费用、学制、入学时间、申请日期、要求、官方来源及核验状态 |
| F03 | 学生背景输入 | 保存或读取专业、原始 GPA 量表／学位等级，以及语言总分和单项分数；不得只保存换算分 |
| F04 | 条件判断 | 按条件返回已满足、未满足或需确认，并显示原因；缺失信息不得自动判为通过 |
| F05 | 项目比较 | 用相同字段比较候选课程，并保留币种和适用入学周期 |
| F06 | 候选清单 | 可添加、移除候选课程；具体保存方式待技术设计确认 |
| F07 | 推荐分档 | 有证据时解释冲刺、匹配和相对稳妥分类；信息不足时不强行分类 |
| F08 | 数据更新 | 保留采集、复核和更新记录，能识别未核验或过期资料 |

本科专业、GPA 和语言成绩是主要输入，但不一定覆盖全部入学条件。项目要求工作经验、先修课或专业资格时，也必须检查或明确标为待确认。

## 不包含

不提交申请、不收费代办、不估算录取概率、不保证录取。初期不要求上传个人证件或成绩单。账户登录、付费功能和自动抓取不是已确认的首批开发任务。

## 待决定事项

- 技术栈、数据库、托管方式和本地运行说明。
- 学生背景是否只在本地保存，以及后续隐私和删除机制。
- 专业映射方法、不可比 GPA 的处理，以及分类展示措辞。
- 当期资料更新频率和数据复核责任安排。
