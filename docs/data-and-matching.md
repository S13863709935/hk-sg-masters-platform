# 数据字段与匹配原则

整理日期：2026-10-05；实现进度更新于 2026-10-06。字段、缺失状态和保守条件判断已经用于本地数据库与程序；当前是开发版本，不是完成全量采集或独立复核的正式招生数据库。

## 数据结构

在现有工作簿基础上，数据库至少区分学校、课程、入学周期、单条要求、来源与复核记录。课程名称不能替代稳定的课程 ID。

| 实体 | 主要字段 |
| --- | --- |
| University | university_id、名称、地区、目录入口、覆盖依据 |
| Programme | programme_id、university_id、官方名称、学位、领域、院系、授课地点 |
| ProgrammeOffering | offering_id、programme_id、入学年度／批次、模式、学制、日期、费用币种及计费基础 |
| Requirement | requirement_id、offering_id、类型、条件、比较符、阈值、原始量表、语言单项、豁免或替代条件 |
| SourceAndReview | source_id、官方 URL、原文必要摘录、适用周期、访问日期、采集人、复核人、状态、冲突说明 |

同一个课程的不同年度、全日制／非全日制或不同招生批次不能混成一组要求。院校的一般规则与项目特别要求须同时保留，冲突时不得静默覆盖。

## 缺失与核验状态

字段内容状态至少区分 `known`、`not_published`、`not_applicable`、`unknown`。内容状态与记录核验状态分开。

记录核验状态可采用 `catalogue_seed`、`programme_page_checked`、`peer_reviewed`、`needs_confirmation` 和 `outdated`。核验工作流由团队确认后实施。

空白学费不是免费；未公布 GPA 不是零分要求；语言豁免也不能直接等同于没有语言要求。

## 判断顺序

1. 确认课程在范围内，并且招生周期与数据来源可识别。
2. 检查学位、专业、先修课、经验或资格等公开必需条件。
3. 仅在量表或学位等级可比且有官方依据时比较学术门槛。
4. 检查接受的语言考试、版本／日期、总分、单项、有效期及适用豁免条件。
5. 汇总已满足、明确未满足及未解决条件，并附来源和理由。

任何已知必需条件未满足时，显示未满足；其余条件未知时仍同时显示未知。没有明确未满足条件但存在未解决必需条件时，显示需确认，不能判为完全达标。

## 分档

优先实现可解释的条件判断。证据支持时，再按现有项目方向提供：

- 冲刺：可核查的必需最低条件已满足，但明确公布的某项偏好条件尚未满足。
- 匹配：可核查的入学条件已满足，并符合学生的专业兴趣。
- 相对稳妥：在可比的公开学术和语言最低要求上有明确余量，背景相关，且没有未解决的必需条件。

条件不完整时不强行分档。这些标签不表示录取概率。公开最低要求未必反映实际录取竞争，满足要求也不保证录取。

原始工作簿中的 35／40／15／10 权重和 80／60／40 分档线是未验证草案，停留在历史资料中，不进入正式判断逻辑。不得编造学校的 GPA 线或跨量表换算。

## 首批测试

- IELTS 总分达标但某单项不足，必须识别具体单项。
- GPA 量表不可比时显示需确认，不自动转换。
- 项目限定本科领域但档案不符合时，显示该条件未满足。
- 未公布某门槛与尚未采集某门槛分别显示。
- 语言豁免前提未知时不直接判为豁免。
- 一个必需条件不满足、另一个未知时，同时保留两种结果。
- 工作经验要求未满足或未提供时，分别显示未满足或需确认。
- 不同招生年度的费用、日期和规则不得混用。

先使用合成学生档案测试，不上传真实成绩单或身份证明。

## 已实施的方向与模式条件（2026-10-31）

官方项目正文明确要求选定的方向可作为同一学位下的独立路径，不新增目录学位。例如 HKUST ILE 的 TESL／TCSL 分别保存完整的部分来源快照；必须明确选择，不能由本科专业、中文背景或现有收藏推断方向。旧的无方向选择若已不足以定位当前条件，会提示重新选择，不静默替换。

仅适用于特定学习选项的规则使用 `appliesTo`，包含本项目／本路径的准确选项 ID、学年、说明和来源查阅日。导入必须校验所属关系、学年及来源日期。未选模式时该项为待确认；选定其他模式时不套用该规则。只有服务端解析出的选择能激活比较，复制 JSON 中的 `selectedOffering` 不能伪造已选择状态。

语言总分、统一单项下限及指定单项下限分别记录。例如 TESL 的 IELTS 写作最低 7.0 与其他单项最低 5.5 同时适用；指定写作要求不能取消其他单项下限。TOEFL 旧版总分 0–120、单项 0–30 与新版总分／单项 1–6 分开校验，保留原始分数，不换算。缺少要求的写作分数为待确认；未公布的其他单项下限不凭空增加。

考试格式限制可记录在具体考试的 `tests.<考试>.atHomeAccepted` 中，并优先于原有规则级同名字段；缺省时沿用规则级政策。港大专业硕士禁止 TOEFL Home Edition 的依据仅作用于 TOEFL，不能推断 IELTS Online 是否获接受。IELTS 单科重考等尚无背景输入字段的条件继续要求材料确认。详情与候选导出保留同一考试级政策，导出只接受布尔值。模式专属语言门槛仍通过明确的 `appliesTo.offeringIds` 绑定。

每个选项的 `deadline` 表示现有记录中最晚的截止日期，`applicationRounds` 保留各轮次、明确的正午时点及原始时区。官方尚会公布后续轮次时，页面使用 Latest recorded cutoff，并在轮次说明中标明当前是早轮或最新已公布轮次；不把该字段解释为整个申请季的最终截止或实时开放证明。

工作总年数达标只表示可比较的年数下限达标，不能证明全职、毕业后取得、职责相关或学校接受其证据。中文测试、语言豁免和资格证明仍须另查。所有现有数据继续保持部分观察，不能因新增自动比较而获得完整资格、录取概率或分档。

路径的最新局部查阅日可以晚于原有费用／日期来源日。必须保留每项原有日期，并具备最新本路径官方页来源；来源日期不能晚于记录日期，不能为满足校验而统一重标历史日期。
