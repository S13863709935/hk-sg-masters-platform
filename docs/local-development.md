# 本地运行与维护

当前本地演示版本：0.1.0；维护说明更新于 2026-11-04。核心功能已进入冻结；本批按用户确认收敛条件摘要与数据质量，数据核验和公开部署尚未完成。本说明不是课程提交材料。

## 开始使用

Windows 优先双击仓库中的 `start-local.cmd`，不是直接运行 `.ps1`。启动窗口显示网址后，打开 `http://127.0.0.1:3102`。保持启动窗口运行，关闭窗口或按 Ctrl+C 会停止服务。启动程序不会自动打开浏览器，也不需要以管理员身份运行。

运行环境需要 Node.js 24 或以上。启动脚本优先使用已安装的 Node；没有合适版本时，会检查当前用户已有的 Codex 内置运行环境。其他组员没有该环境时，应安装 Node.js。网站运行无需安装额外软件包。

启动器会切换到自己的项目目录；重复启动且同一端口已有 GradPath 时，会显示已有网址，不再启动第二个实例。若想加载刚修改的服务代码或源文件，先停止原服务，再启动，不能靠再次双击实现重载。

只有在 `node --version` 显示 24 或以上时，才直接在项目目录运行：

```text
node server/index.mjs
```

或使用 `npm start`。本机 2026-10-23 检查时默认 Node 是 16.20.2，启动器可使用已有的内置 Node 24.19.0；这不改变全局默认版本。其他电脑没有该内置环境时，需要另行准备 Node 24 或以上。不要把旧版 Node 的报错当成需要执行 `npm install`。

端口已占用时，可以在项目目录的 PowerShell 中运行：

```powershell
$env:PORT = '3103'
.\start-local.cmd
```

然后打开 `http://127.0.0.1:3103`。环境变量只影响该终端及其子进程；新终端仍使用默认值，除非自行设置过系统变量。`localhost` 与 `127.0.0.1`、不同端口和不同浏览器的收藏与背景存储相互独立，演示时应固定同一网址。

`.env.example` 只是字段说明，复制为 `.env` 也不会自动加载。程序识别 `PORT`、可选 `DB_PATH` 和可选 `ADMIN_TOKEN`。日常使用不设置 `DB_PATH`，即可保留默认数据库；临时验收才使用 `DB_PATH=:memory:`，停止服务后其中的数据即消失。不要在临时测试终端里继续维护日常数据库。

详情页可临时选择方向；选择后，详情、背景检查、比较和候选导出使用该方向自己的要求、费用和年份。不选择时继续按未解决的分组处理。未主动记忆的方向选择在重载后清除，不清空已有背景或候选列表；只有点击 `Remember these choices` 才保存选项编号。服务启动时校验并读取方向快照；修改该 JSON 后重启服务。运行时不支持后台导入方向数据，`/api/export` 仍导出父目录数据；版本化方向文件应单独保存，候选导出包含所选方向标识。

SQLite 数据库首次启动时创建在 `data/local/platform.sqlite`，不上传 GitHub。数据库含学校、课程、学习选项、条件、元数据及变更日志，不含学生档案表。重启不会清除导入的课程修改。

首次项目页更新可以在目录／范围说明之下更新未被改过的种子或扩展线索；系统比较历史原始数据，不仅凭状态标签覆盖。人工修改和独立复核仍受保护，首次来源冲突在重启后继续可见，不会自动消失。相关回归只在隔离数据库验证，没有为同步数量而改动日常数据库，见 [首次来源更新修复](progress/2026-10-24-local-first-check-refresh-fix.md)。

`node scripts/check-data.mjs` 从仓库源文件构建内存实例，检查的不是上述日常数据库。实际运行实例请看 Data workspace；本地显式导入后两处数字可能不同。不要为了消除差异而删除或替换数据库。

## 五分钟本地演示

1. 启动后进入 Explore programmes，搜索 `Master of Computing` 并选择 NUS。检查来源状态和未知条件，而不只看课程名称。
2. 保存两个项目，勾选 Compare，进入并排比较；打开详情选择学习模式，查看年份、费用基准与来源日期如何保持分开。
3. 如需演示背景检查，只输入明确标记为测试的合成背景，不使用同学的真实成绩。GPA 同时填原分数和原量表。默认不勾选记忆背景；“需确认”不是满足全部门槛。
4. 在 My shortlist 导出候选 JSON。文件包含公开项目事实、选项编号和未解决条件，不包含背景或匹配结论；这不是申请或录取证明。
5. 结束时 Clear background，移除演示收藏、清空比较。若主动记忆过选项，使用 Forget remembered choices；移除项目最后一个所属清单也会清理该项目的记忆。确认清理结果，再停止服务。

集中验收只覆盖已记录的桌面浏览器流程和模拟窄屏；不替代真实手机、辅助技术或生产托管测试。见 [实际验收记录](progress/2026-10-23-local-site-acceptance.md)。

## 核验和导入

维护前先备份。先从数据工作台导出 catalogue JSON，复制待更新的完整父项目对象到新的批次文件；不要使用候选清单导出代替导入批次。顶层使用 `schemaVersion: 1` 和 `programmes` 数组，字段格式参考 `data/checked-programmes.json`。每条结构化要求必须带大学官方 HTTPS 来源。

命令行导入前停止正在使用同一数据库的服务，再运行：

```text
node scripts/import-data.mjs path/to/checked-batch.json
```

批次会整体校验并在一个数据库事务内导入。任何一条不合法时全部回滚。修改记录包含实际时间、原因及修改前后内容。`peer_reviewed` 状态必须记录不同的采集人与复核人，不能冒填团队姓名或完成状态。

修改源文件后重启服务。`catalogue.json` 只用于初次建库；`catalogue-expansion.json` 只添加新 ID，不覆盖既有用户更新；`checked-programmes.json` 按项目指纹比较，只自动更新没有人工修改冲突的记录。未变的源记录不会覆盖后续人工修改；已复核记录也不会被自动降级。冲突会显示在数据工作台的待协调清单中，需比较旧值与新来源后显式导入。日常采集更新使用批次导入，不编辑原始工作簿或删除数据库。

`programme-scope-audit.json` 只添加带来源和日期的范围判定，不改入学条件或原始表格。研究型项目从默认搜索／匹配中排除，但原 ID、详情和导出记录保留；这是项目范围排除，不是学生成绩不达标。

`directory-links.json` 是目录证据叠加层：只补官方目录名称、链接和分路径参考，不修改原记录的入学要求、费用、日期或复核状态。合并索引的方向／语言／双学位路径必须先选定并分别核实，不能使用共同或另一方向的条件判断资格；这些合并记录始终保留路径未知项，不产生分档。

## 可选目录研究工具

`collect-directory.mjs` 对指定公开目录进行有超时和体积限制的读取，最多两个请求并行；拒绝或读不到的页面保留为未知，不绕过访问限制。HTML 解析使用用户显式提供的 Python 及已安装的 lxml，仅用于研究，不是网站运行依赖。候选输出不自动变成已核验招生数据。

`build-directory-inventory.mjs` 使用 2026-10-08 已保存的目录快照和本轮范围规则生成排除清单及未核验扩展层，保留已有 ID。目录结构／学校范围变化时需重新审查规则，不能把该脚本当成无需人工检查的长期爬虫。重复运行只更新同一批研究派生文件，不产生新周次或伪造贡献。

`build-sg-directory-inventory.mjs` 使用 2026-10-13 的冻结观察记录，生成新加坡目录交叉表及未核验线索。旧版生成器拒绝覆盖较新批次；SUSS 的 28 条仍是待逐项目核实的目录线索，不能当作已确认授课型硕士总数。它不会替代 NUS／NTU 的后续盘点。

`build-dynamic-directory-inventory.mjs` 使用同日 NUS／NTU 全部动态分页的冻结观察，生成新的目录交叉表、未核实线索和链接证据。136／113 是官网筛选后的目录条目数，不是最终独立硕士数量。通用 Computing、Accounting 名称对应和部分联合路径仍保留待协调状态；没有套用 General Track 或其他方向的入学规则。

## 网页导入权限

默认关闭。需要使用时，在启动前将 `ADMIN_TOKEN` 设置为至少 24 个字符的随机令牌，再通过数据工作台输入该令牌和 JSON 文件。网页不保存令牌，鉴权成功且来源校验通过才会写入数据库。令牌不得提交到仓库。

`.env.example` 只是字段示例，程序不会自动读取它；通过启动服务的终端设置环境变量。未设置令牌时本地命令行导入仍可使用。

## 判断规则与局限

### 入学批次与学习模式

详情中的 `Intake and study mode` 可选择同一项目／已选方向下的具体学习选项，也可恢复全部选项。卡片、比较、候选清单、导出及背景检查共享当前选择，分别保留年份、模式、费用基准、申请日期及申请者类别备注。选择默认临时有效；更换方向会清除旧学习选项，不跨方向套用费用。用户可另行点击 `Remember these choices` 主动保存选项编号，刷新后先校验再恢复，失效项保留提示而非自动替换，见 [remembered-programme-options.md](remembered-programme-options.md)。

该选择只筛选已记录事实，不证明该批次／模式的完整入学条件已核实。因此背景检查另加一项“批次和模式适用性待确认”，不会据此启用推荐分档。实现边界见 [study-option-selection.md](study-option-selection.md)。

大学专属申请者类别层现有教大 MPPM January／September 2027、CityU Applied Economics、HKU CS 以及 HKBU Communication／Business Management September 2027 全日制的具体上下文，以及科大 DISC／CIEM September 2027 全日制／兼读制和 NUS DSML August 2027 全日制／兼读制，本批新增 CityU MBA、AI、AI for Sciences、Cybersecurity 四组的分类费用及 DTTI、Global Business Management、Management and Innovation、Marketing 四组的分类截止日（合计 15 个学习选项）；当前文件合计 33 组上下文／68 类别（2026-10-30），具体适用范围以每组绑定为准。NUS 每个学制只有普通国际、符合返还条件的国际校友和公民／PR 三种有证据的费用情形；不推断身份或资助状态，不把有资助的本地学生套入无资助优惠，费用 PDF 视觉复核仍待完成。科大两类最终截止不同，未确认开放日；旧收藏只选学制时仍须明确选择类别。CIEM 二月截止相同，不使用九月分类轮次；SMU 未确认精确截止及杂费模型，不创建虚构分类上下文。教大九月有自己的中央日程及新申请费，不沿用一月值。浸大传播学兼读制适用性仍待确认，没有创建其非本地类别。不能把这些类别规则推广到其他项目、模式或入学批次。未选类别不默认套用非本地价格；选中后分别显示该类别有证据的学费、单独申请费、截止日期和对应来源日期，未知费用仍留空。不能从人在新加坡、国籍或背景资料推断本地身份。更换方向或批次会清除当前类别，但不会自动覆盖主动保存的选项；未主动保存时刷新会重置。选择不写入历史地址，也不与成绩资料一起自动保存。独立复核和完整性缺口不变。实现契约及最早示例见 [applicant-category-selection.md](applicant-category-selection.md)，当前覆盖以 Data workspace 和源文件为准。

### 申请日期与学术条件分开

卡片、详情及比较单独显示申请日期判断；候选导出包含 `applicationTimeline`、比较日期、来源日期和 `livePortalChecked: false`。以香港／新加坡的 UTC+8 日历比较已记录的日期，不访问申请门户、不重写源文件，也不改变学术匹配结果或分档。

状态包括尚未到记录的开放日、处于已记录日期范围、截止日当天、记录的截止日期已过、日期待确认、日期需协调、各学习选项日期不同、方向未选择及未经来源核查。只有截止日、循环月份、年份未确认或日期覆盖标记未解决时，不据此声称申请已开放。截止当天不默认可申请至 23:59；具体时刻、申请者类别、提前满额或延期仍需查看官网。

详情中的“Refresh date comparison”只按新的比较日期重新计算已有资料，不代表重新读取学校网页。方向选择同时用于无背景浏览的卡片与过滤、详情、背景检查和比较；方向 ID 属于公共课程选项，不包含学生背景，也不写入页面历史地址。原始目录导出仍是来源数据，不把计算出的日期状态变成已核验事实。

### 学术条件

2026-10-30 增加 `Recorded comparisons met` 筛选与摘要。必需的 degree／major／GPA／classification／language／experience 比对单独计数；manual、来源完整性、路径／批次／申请者类别条件保留原状态。全部已记录可比条件通过且至少有一条时可进入此筛选，但总体仍可为 `needs_confirmation`，没有完整条件及独立复核仍不分档。目录线索、已知必需缺口、范围外记录或失效保存选项不进入此筛选。

香港八校现有记录已另作 [统一质量表](research/hk-existing-records-quality-2026-10-30.md)。可运行 `node scripts/school-quality.mjs --school HK-HKBU --as-of 2026-10-30 --records checked --format markdown`：保留该校完整本地目录数量，表内只列已存在的部分观察；旧转入／范围外参考与活跃字段缺漏分开计数。省略 `--records` 仍按原行为输出该校所有本地记录，不会重写先前的 SMU 报告。三条资格字段的更新不重置费用类别来源日期，也不改变原匹配规则。

学校质量工具示例：`node scripts/school-quality.mjs --school SG-SMU --as-of 2026-10-30 --format markdown`。它只审计本地已收集字段，不表示重新读取全部官网，也不把“未公布 GPA”当作零门槛。[本次 SMU 统一表](research/smu-school-quality-2026-10-30.md)覆盖现有 17 条记录；其中 MSE／MSFE 截止延至 11 月 30 日，MDSE 页面差异仍保留待确认。

必需条件有明确失败时显示缺口，同时保留其他未知条件。没有失败但有未知必需条件时显示需确认。只有全部已记录必需条件可判断时，才显示已核查条件达标，不表示学校确认最终资格。

GPA 仅比较相同原始量表，不线性换算。荣誉等级不从 GPA 推断。明确的相关专业、英语豁免、院校认可及同等资格仍需要学校判断。托福版本与 2026-01-21 前后的考试日期分别检查。

分档只对条件完整、路径明确且有独立复核的记录启用。相对稳妥表示自报成绩在相同尺度上高于已记录最低值并且背景相关，不设额外录取线，也不估算录取概率。未知偏好条件同样会阻止分档。

## 隐私及运行边界

服务只监听 `127.0.0.1`，不是公开部署方案。外部 Origin 的写请求被拒绝，后台导入需要令牌，静态文件白名单不暴露服务器代码、原始数据文件或数据库。

背景只临时传给本地服务做判断，不入库、不写请求日志。只有用户勾选保存时，背景才存入当前浏览器。候选清单保存在浏览器；方向、批次、模式和申请者类别仅在用户另点 `Remember these choices` 时保存编号，不保存旧费用、旧日期或成绩。`Forget remembered choices` 只移除选项记忆，不移除项目；共享设备须谨慎。导出候选不包含背景，失效选项独立列为 unresolved，不用默认费用代替。页面的清除背景功能不删除收藏或另外保存的选项。

公开部署之前仍需另行评估 HTTPS、鉴权、流量限制、备份、隐私规则和最新课程数据，不能直接向公网绑定当前本地预览。

## 备份与恢复边界

- 普通使用只需在停止服务后复制 `data/local/platform.sqlite` 到自己的非仓库备份目录；如果存在同名 `-wal`／`-shm` 伴随文件，也一并保存。不要在数据库运行中直接替换它。
- 数据库备份保留本地导入和变更日志；同时保留对应代码版本、`data/route-programmes.json`、`data/applicant-contexts.json` 及其他版本化源文件。只有 Git 代码不能恢复未提交的数据库导入。
- Export catalogue JSON 不包含独立方向／申请人文件或数据库变更日志，因此不是完整系统备份。Export shortlist 只是候选项目快照，也不能恢复浏览器背景、收藏状态或整个数据库。
- 浏览器存储独立于数据库。换端口、换浏览器或清空站点数据可能看不到原来的收藏；这不表示服务器删了数据。不要替用户自动保存或同步背景。
- 恢复前先保留当前文件副本，确认目标路径及版本兼容，并停止服务。未经明确核对，不删除数据库、不覆盖已有备份、不用旧源文件批量替换人工更新。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| `node:sqlite` 不可用、Node 版本过旧 | 使用 `start-local.cmd`；直接运行前确认 `node --version` 至少为 24。安装依赖不能修复旧运行时。 |
| `.ps1` 提示禁止执行脚本 | 改用项目提供的 `.cmd` 入口。它仅在当前启动进程使用执行参数，不要求修改系统策略；若设备策略仍阻止，遵守设备管理要求，不全局关闭防护。 |
| 地址打不开或端口已占用 | 查看启动窗口是否仍运行，使用窗口显示的地址。换 `PORT` 时使用相同端口访问，不结束不属于本项目的服务。 |
| 新代码似乎没生效 | 确认使用本地开发分支，停止原服务后重新启动，再刷新。重复启动提示不是热更新；不要通过删除数据解决。 |
| 背景存在，但条件检查暂不可用 | 可继续浏览；使用 Retry requirement checks 或重新提交 My background。重试依据存储的来源，不是实时核查大学网页。 |
| 保存选项无法校验，启动停在提示页 | 使用 Try again；仍不成功时保留原存储和错误现象再排查，不自动替换选项或清空站点数据。服务恢复后，按提示更新或忘记失效选项。 |
| 数据工作台显示来源冲突 | 比较本地修改与新源文件，人工协调后显式导入；不要自动覆盖已复核记录，也不把冲突隐藏成已完成。 |
